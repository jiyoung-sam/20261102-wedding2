# 감성 미니멀 웹 청첩장

## 레이아웃
PC와 모바일 모두 1단 세로형 원페이지 구성입니다. PC에서도 좌우 3열로 나뉘지 않고 초대 인사 → 스토리 → 갤러리 → 예식 안내 → 오시는 길 → 마음 전하실 곳 순서로 이어집니다.

## 실행 방법
1. 압축을 풉니다.
2. `index.html` 파일을 Chrome 또는 Edge에서 엽니다.
3. 실제 배포 시 폴더 전체를 GitHub에 올리고 Vercel에서 배포합니다.

## 폴더 구조
- index.html : 웹페이지 구조
- css/style.css : 디자인과 반응형 레이아웃
- js/script.js : 사진 팝업과 계좌번호 복사 기능
- images/ : 시안에서 추출한 실제 이미지 파일

## 수정할 내용
`index.html`에서 예식 날짜, 시간, 예식장 주소, 신랑·신부 이름과 계좌번호를 실제 정보로 바꿔 주세요.
Google 지도 검색어와 길찾기 목적지도 실제 예식장 이름으로 변경하면 됩니다.

## 참고
지도는 Google 지도 임베드/길찾기 링크를 사용합니다. 지도 검색 결과는 예시 장소이며 실제 예식장 주소로 수정해야 합니다.
웹폰트는 Google Fonts를 사용하므로 인터넷 연결 시 적용됩니다.
